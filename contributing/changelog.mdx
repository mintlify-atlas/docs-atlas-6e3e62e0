  <Accordion title="4.2.2 — Features and translations">
    [View source tree](https://github.com/EmulatorJS/EmulatorJS/tree/a796c4a3866652d1b6cb74a2b90e9552955c2b13)

    **Features and improvements**
    - Prioritize `gameName` over `gameUrl` for the local storage identifier
    - Add `EJS_dontExtractBIOS` option ([@pjft](https://github.com/pjft))
    - Add `saveSaveFiles` event triggered when save files are updated
    - Add `saveDatabaseLoaded` event triggered when the `/data/saves` directory is mounted
    - Add ability to set a system save interval
    - Add `EJS_hideSettings` option to hide entries from the settings menu
    - Add dropdown selection for gamepads
    - Add `dosbox_pure` core (requires threading)
    - Add toggle for direct keyboard input
    - Add setting to enable/disable mouse lock
    - Add option to disable `alt` key when using direct keyboard input
    - Add Romanian translation file ([@jurcaalexandrucristian](https://github.com/jurcaalexandrucristian))
    - Rework internal method of getting user settings; add `this.getSettingValue`
    - Redo scrolling in settings menu
    - Redo about menu CSS
    - Redo toolbar visibility method ([@allancoding](https://github.com/allancoding))
    - Redo touchscreen detection ([@allancoding](https://github.com/allancoding))
    - Write core settings file before loading the core
    - Correct N64 virtual gamepad inputs
    - Cleanup famicom controls
    - Change path to `retroarch.cfg`
    - Add `joystickInput` property for virtual gamepad buttons
    - Remove `this.listeners`

    **Bug fixes**
    - Fix CSS parsing when setting a background image ([@kellenmace](https://github.com/kellenmace))
    - Delete old screenshot file before saving a new one ([@gantoine](https://github.com/gantoine))
    - Properly handle failed save states
    - Fix unknown axis events being discarded
    - Fix setting gamepad axis to input values 16 to 23
    - Fix build stack size when building cores
    - Fix CHD support

    **Translations**
    - Update Japanese translation ([@noel-forester](https://github.com/noel-forester))
    - Update Korean translation ([@SooHyuck](https://github.com/SooHyuck))
    - Attempt to auto-detect system language; add `EJS_disableAutoLang` to opt out
  </Accordion>

## Earlier releases

<Accordion title="2.x and 1.x releases">
  **2.3.x** — Shader additions, custom virtual gamepad UI, custom control mappings, FPS counter, gamepad handler rewrite, `EJS_disableLocalStorage`, save files auto-saved to IndexedDB every 5 minutes.

  **1.x** — Minification pipeline, modular file structure, beta cores (NDS, GB, N64), screen orientation lock, netplay support, localization, custom virtual gamepad configuration, `EJS_startOnLoaded`, quick save state slots.

  **1.0** — Official release of beta cores in production, old netplay server support, screenshot and screen recording with game name as filename.

  For full details, view the [CHANGES.md](https://github.com/EmulatorJS/EmulatorJS/blob/main/CHANGES.md) file in the repository.
</Accordion>
