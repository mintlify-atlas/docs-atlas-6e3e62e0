---
title: "Supported systems"
description: "All gaming systems supported by EmulatorJS, with EJS_core values and the libretro cores that power them."
---

EmulatorJS supports 30+ classic gaming systems via libretro cores compiled to WebAssembly. Use the `EJS_core` value in the table below when configuring `window.EJS_core` on your page.

```javascript
window.EJS_core = "snes"; // example: Super Nintendo
```

<Note>
  When a system lists multiple cores, EmulatorJS uses the first one by default. The active core can be changed from the in-emulator settings menu under **Core**. Setting `window.EJS_forceLegacyCores = true` disables WebGL2 detection, causing the emulator to load the non-WebGL2 core variant even when WebGL2 is available.
</Note>

## Sega

| System | `EJS_core` value | Libretro cores |
|---|---|---|
| Sega Master System | `segaMS` | `smsplus`, `genesis_plus_gx`, `genesis_plus_gx_wide`, `picodrive` |
| Sega Mega Drive / Genesis | `segaMD` | `genesis_plus_gx`, `genesis_plus_gx_wide`, `picodrive` |
| Sega Game Gear | `segaGG` | `genesis_plus_gx`, `genesis_plus_gx_wide` |
| Sega CD | `segaCD` | `genesis_plus_gx`, `genesis_plus_gx_wide`, `picodrive` |
| Sega 32X | `sega32x` | `picodrive` |
| Sega Saturn | `segaSaturn` | `yabause` |
| Sega (auto-detect) | `sega` | `genesis_plus_gx`, `genesis_plus_gx_wide`, `picodrive` |

<Tip>
  Use `segaMD` for Mega Drive / Genesis ROMs, `segaMS` for Master System, and `segaGG` for Game Gear. The generic `sega` core is useful when the exact hardware generation is unknown.
</Tip>

| PlayStation Portable | `psp` | `ppsspp` |

</Warning>

## Threading and WebGL2 requirements

Some cores have additional browser requirements:

| Requirement | Affected cores | How to enable |
|---|---|---|
| SharedArrayBuffer (threading) | `ppsspp` (PSP), `dosbox_pure` (DOS) | Set `window.EJS_threads = true`; server must send COOP/COEP headers |
| WebGL2 | `ppsspp` (PSP) | Required browser support — most modern browsers include this |
